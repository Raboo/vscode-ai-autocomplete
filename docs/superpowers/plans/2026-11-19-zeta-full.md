# Full Zeta 2.1 Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zeta 2.1 gets Zed-like inputs (region, blocks, context mix, history context lines, predicted cursor), and every Next Edit format gets definitions of nearby symbols from the language server as related context.

**Architecture:** Pure logic in `src/nextEdit/` (region sizing, budgets, history rendering, `related.ts` for identifiers, excerpts and merging, the Zeta parser), unit-tested in `test/unit/nextEdit/`. The language-server lookup lives in `src/nextEdit/vscode/definitions.ts`; the controller wires it into requests and warm-ups and moves the cursor after accepts.

**Tech Stack:** TypeScript, VS Code API (`vscode.executeDefinitionProvider`, `vscode.executeDocumentSymbolProvider`), jsdiff, vitest, `@vscode/test-electron`.

**Spec:** `docs/superpowers/specs/2026-11-19-zeta-full-design.md`

## Global Constraints

- Sweep and chatXtab keep their region, budgets and history rendering; their only change is receiving definitions (and the `...` line after snippets).
- Definitions and snippets go out only when the backend's extra context is on and `aiAutocomplete.nextEdit.definitions` is true; never from excluded files (`completions.disableInFiles`, `completions.disableInLanguages`), the current file, non-`file` schemes, or files over 1 MB.
- Lookup cap 100 ms; at most 8 distinct identifiers; symbols up to 20 lines kept whole; without symbols, 10 lines from the definition line.
- Zeta region ≤ 1225 chars and ≤ 40 lines; blocks `ceil(lines / 16)`, near-equal, larger first; file context outside the region 525 chars; history and related each half of (total chars − 525).
- No code copied from Zed. Paths and code text in logs only with `debug.logPrompts`.
- Only `src/nextEdit/vscode/*` (and the other allowlisted files) import `vscode`.
- Commits: Conventional Commits, no trailer, explicit-path staging, never `*.swp`.

## Review Focus

- A definition provider that never answers or throws: the request still goes out after ≤ 100 ms with snippets only (Task 5 integration test with a provider that hangs).
- Typing inside a word keeps the related section byte-identical between requests, so the prompt cache keeps working (Task 4 cache test: same region start and identifier set → same items).
- The predicted cursor after the user typed between show and accept: no cursor move when the document no longer holds the accepted text (Task 6 test).
- A region at the start or end of the file, and a file shorter than the region budget: the region grows on the other side or covers the whole file (Task 1 tests).
- A Zeta answer with `<|user_cursor|>` twice, or outside the rewritten span: no predicted cursor, and the tag never reaches the document (Task 6 tests).

### Task 4: Related context, pure parts

**Files:**
- Create: `src/nextEdit/related.ts`
- Modify: `src/nextEdit/history.ts` (`RecentSnippets` adds `...`)
- Test: `test/unit/nextEdit/related.test.ts`, `test/unit/nextEdit/history.test.ts`

**Interfaces:**
- Produces in `related.ts`:
  - `pickIdentifiers(lines: string[], region: LineSpan, cursor: { line: number; character: number }, max = 8): { name: string; line: number; character: number }[]`: words matching `/[A-Za-z_$][\w$]*/`, length ≥ 3, not in a small keyword set, nearest to the cursor first (line distance, then column), one occurrence per name.
  - `interface SymbolNode { range: LineSpan; children: SymbolNode[] }`
  - `excerptFor(lines: string[], symbols: SymbolNode[] | undefined, line: number): LineSpan[]`: the innermost symbol containing `line`; whole when ≤ 20 lines; else its first line and each child's first line; without symbols `[line, line + 9]` clipped to the file.
  - `mergeExcerpts(path: string, lines: string[], spans: LineSpan[]): Snippet`: spans sorted and joined when overlapping or adjacent, `...` between gaps and after the last when the file continues past it, none before the first.
  - `class RelatedCache`: `key(uri: string, regionStart: number, names: string[]): string`, `get(key): Snippet[] | undefined`, `set(key, items: Snippet[]): void`, `forgetTarget(path: string): void` (drops entries containing that path), at most 32 keys (oldest out).
- `RecentSnippets.add` appends `\n...` when the window ends before the file's last line.

- [x] Tests for each function from the bullets above, including: identifiers sorted by distance; `const`/`return`/`function` skipped; a 50-line class with two methods → its first line, `...`, method 1's first line, `...`, method 2's first line, `...` when the file continues; two spans of one file merged in row order; the cache returns the same array for the same key regardless of document version; a snippet ending at the last line has no `...`.
- [x] Implement.
- [x] Tests, typecheck, lint pass.
- [x] Commit: `feat: pure building blocks for definitions as Next Edit context`
