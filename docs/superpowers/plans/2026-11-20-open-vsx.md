> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Releases publish to Open VSX as `raboo.ai-autocomplete`; 1.4.0 can be published by hand.

**Architecture:** One more set of steps in the `vsix` job of `.github/workflows/release-please.yml`, plus a `workflow_dispatch` entry point; docs.

**Tech Stack:** GitHub Actions, `ovsx`, release-please.

**Spec:** `docs/superpowers/specs/2026-11-20-open-vsx-design.md`

## Global Constraints

- The token comes only from secret `OPEN_VSX_TOKEN` via env `OVSX_PAT`; never on a command line, never echoed.
- Actions pinned by full SHA with `# vX.Y.Z`; least-privilege `permissions:`; `timeout-minutes` on every job; job ids `release-please` and `vsix` unchanged.
- Runtime dependencies unchanged (`ovsx` is a devDependency).
- Commits: Conventional Commits, no trailer, explicit staging.

## Review Focus

- Missing secret: the job still uploads the GitHub asset and skips Open VSX with a notice (test in `repoAutomation.test.ts` pins the guard).
- `create-namespace` when the namespace exists: the job goes on (the guard only ignores that answer).
