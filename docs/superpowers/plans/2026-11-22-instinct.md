# Instinct Next Edit Format Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Next Edit with Continue's Instinct model: an `instinct` chat format, `auto` selection by model id, and an `instinct-7b` local recipe.

**Architecture:** A new `ChatFormat` in `src/nextEdit/formats/instinct.ts` (messages, done, parse) reproducing the training-data prompt; wired into `formatIdFor`/`pickFormat`, the settings enum, a preset row and the recipe list.

**Tech Stack:** TypeScript, vitest.

**Spec:** `docs/superpowers/specs/2026-11-22-instinct-design.md`

## Global Constraints

- The prompt text (system prompt, user prefix, headings, tag spellings, path quoting) is exactly as in the spec's "The format" section; the system prompt says "AI assistant" and ends with `"\n\n"`.
- `src/nextEdit/formats/instinct.ts` starts with `// Portions adapted from Continue core/nextEdit @ 5522c6f44ca0ac3528b37244818fbfa39b5af470 (Apache-2.0). Copyright Continue Dev, Inc.`, and `THIRD_PARTY_NOTICES.md` gets a `## Continue (continuedev/continue)` entry naming `core/nextEdit/constants.ts`, `core/nextEdit/templating/instinct.ts`, `core/nextEdit/templating/NextEditPromptEngine.ts` and the full Apache-2.0 notice reference (same shape as the Sweep AI entry).
- Formats never import `vscode`.
- Region: cursor −1/+5 lines, ignoring the size settings. Window: ±25 lines around the cursor, clipped further by `budgets.fileChars`.
- Recipe values (verbatim): id `instinct-7b`, label `Instinct 7B`, repo `continuedev/instinct-GGUF`, revision `c3f24799cc492d3252505628f49760f2fe133f43`, file `instinct-Q4_K_M.gguf`, bytes `4683073376`, sha256 `65eff06597c533456ac031479f31175e894e9e6ff79a562ed4d1f859f154af29`, license `Apache-2.0`, uses `['completions', 'nextEdit']`, modelName `instinct`, contextTokens `8192`, no note, placed right after `zeta-2.1`.
- Commits: Conventional Commits, no trailers, stage by explicit path.

## Review Focus

- Cursor on the first or last line of the file: the region and window clip at the file edges and the cursor tag still lands inside the region.
- A file, edit or snippet containing an Instinct tag (e.g. editing this extension's own `instinct.ts`): the file/history case gives `problem()`, the snippet is skipped; never a prompt with a stray tag.
- The model answers with a ``` fence or echoes `<|editable_region_start|>`/`<|user_cursor_is_here|>`: the parser still returns the clean region lines.
- No history and no snippets: both headings still appear with empty bodies, and the user message is still well-formed.
- A model id like `instinct-zeta-mix` or `ollama nate/instinct:latest`: `auto` picks `instinct` (checked before Zeta/Sweep).

- [ ] **Step 1: Write the failing tests** in `test/unit/nextEdit/instinct.test.ts`:
  - `instinctRegion(10, 100)` is `{ start: 9, end: 15 }`; `instinctRegion(0, 3)` is `{ start: 0, end: 2 }`.

  - Golden user message for a small input (one snippet `{ path: 'a.ts', text: 'export const a = 1;' }`, two history entries with `contextText`, a 40-line file, cursor at line 20 char 4) equals the exact expected string built per the spec layout: prefix sentence, `### Context:\n\n<|context_file|> \`a.ts\`\n<|snippet|>\nexport const a = 1;\n\n### User Edits:\n\n` + newest entry first as `User edited file "<path>"\n\n\`\`\`diff\n<contextText>\n\`\`\`` joined by `\n\n`, then `\n\n### User Excerpt:\n"<path>"\n\n` + window lines with the region tags on their own lines and `<|user_cursor_is_here|>` inserted at line 20 char 4, ending in `\n\n`.
  - The system message is `INSTINCT_SYSTEM`, which contains `Your role as an AI assistant is` and ends with `"errors.\n\n"`; with `systemSuffix` it is `INSTINCT_SYSTEM + systemSuffix` joined as chatXtab does.
  - Empty history and snippets: the message contains `### Context:\n\n\n### User Edits:\n\n\n### User Excerpt:` (headings kept, bodies empty).
  - The window is at most 25 lines either side of the cursor; with a tiny `budgets.fileChars` it is shorter but always contains the whole region.
  - `stableChars` equals the index of `### User Edits:` in the user message.
  - `problem()` returns a reason when a file line or history `contextText` contains `<|snippet|>`; a snippet containing `<|editable_region_end|>` is left out of the message.
  - `parseInstinct('  a\n  b', true)` → `{ kind: 'rewrite', lines: ['  a', '  b'] }`; a `<|user_cursor_is_here|>` inside a line is removed; lines equal to `<|editable_region_start|>` / `<|editable_region_end|>` are dropped; `'```ts\n  a\n```'` → lines `['  a']`; `''` and `'\n  \n'` → `{ kind: 'invalid', why: 'empty' }`.
  - `instinctFormat.done('anything')` is `false`.
